# ShadowDesk 🛡️
**Developed by Amjed Khaled**

ShadowDesk is an advanced, ultra-lightweight desktop privacy tool for Windows that allows you to seamlessly hide specific windows when sharing your full screen on applications like Zoom, Microsoft Teams, Discord, Google Meet, and OBS.

## Key Features

- **Exclude From Capture:** Target applications remain fully visible and usable on your monitor, but appear 100% invisible to anyone viewing your shared screen or recording.
- **Ghost Mode (Self-Stealth):** ShadowDesk automatically hides its own window and controls from screen sharing and previews so viewers will never suspect a privacy tool is running.
- **Taskbar & Alt+Tab Cloaking:** Completely remove hidden windows (and ShadowDesk itself) from the Windows Taskbar and Alt+Tab switcher.
- **Instant Keyboard Shortcuts:**
  - **`F8`** (or `Ctrl + Shift + H`): Instantly restore hidden/minimized windows to the front when you need them, or minimize them out of sight with a single tap.
  - **`F7`**: Instantly toggle the ShadowDesk control panel.
- **Live Desktop Preview:** Real-time preview showing exactly what remote viewers see.

## Getting Started

Run `ShadowDesk.exe` directly, or launch it with command-line arguments:
```powershell
ShadowDesk.exe --help
```

### Hotkey Quick Reference
| Key | Action |
| --- | --- |
| **`F8`** or **`Ctrl + Shift + H`** | Toggle Show / Minimize protected windows |
| **`F7`** | Toggle ShadowDesk window itself |
